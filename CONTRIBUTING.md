# Contributing to placekit-py

Thank you for your interest in contributing to `placekit-py`.

This project is currently in early development. Contributions, ideas, bug reports, and documentation improvements are welcome.

## Before contributing

For now, please open an issue before working on large features or public API changes.

Examples of large changes:

- Adding a new provider
- Changing public classes or function names
- Changing return types
- Adding new dependencies
- Changing package structure

Small improvements such as typo fixes, test improvements, and documentation updates can be opened directly as pull requests.
